REGLAS DE FIREBASE (Realtime Database -> Reglas)
================================================
Pégalas completas y pulsa Publicar. Hazlo DESPUÉS de comprobar que ya puedes entrar a la app con tu usuario y PIN
(si las publicas antes, el técnico no podría editar el catálogo).

{
  "rules": {
    ".read": true,
    "reportes": { ".write": true, ".indexOn": ["profId", "equipoId"] },
    "historial": { ".write": true },
    "salones": { ".write": "auth != null && auth.token.firebase.sign_in_provider === 'password'" },
    "equipos": { ".write": "auth != null && auth.token.firebase.sign_in_provider === 'password'" },
    "preventivo": { ".write": "auth != null && auth.token.firebase.sign_in_provider === 'password'" },
    "fotos": { ".write": "auth != null && auth.token.firebase.sign_in_provider === 'password'" },
    "usuarios": { "$uid": { ".write": "auth != null && auth.uid === $uid" } }
  }
}

Qué hacen:
- Leer: cualquiera puede leer (Control Fitness y Control Gerencia leen sin iniciar sesión).
- reportes e historial: los instructores los crean y los quitan desde Control Fitness, sin cuenta aquí.
  El índice por profId permite que cada instructor consulte solo los suyos; el de equipoId, ver si un equipo ya tiene un reporte.
- Catálogo (salones, equipos), preventivo, fotos y usuarios: solo se escriben con sesión iniciada con usuario y PIN.
