CONTROL MANTENIMIENTO
=====================
App del área de mantenimiento del club. Los instructores reportan equipo desde Control Fitness, el técnico lo
atiende aquí, y Control Gerencia ve el resumen.
Mismo aspecto que Control Gerencia: en computadora, menú lateral; en celular, encabezado con degradado y barra
inferior flotante. (css/main.css, app-mobile.css y app-desktop.css son los de Gerencia.)

Base de datos: Firebase, proyecto registro-mantenimiento-9854c (Realtime Database).
Repositorio:   cfitnesscampestre-star/control-mantenimiento (GitHub Pages).

SEMÁFORO DE REPORTES
--------------------
ROJO      "nuevo"     nadie lo ha abierto. Siempre rojo, sea normal, urgente o "no se puede usar".
AMARILLO  "atencion"  en cuanto el técnico abre el reporte pasa solo a "en proceso".
VERDE     "resuelto"  el técnico lo marcó resuelto (con su diagnóstico). El instructor lo elimina para quitarlo.
Filtros de la lista: Todos / No se puede usar / Urgente / Normal.

PANTALLAS
---------
Reportes          lista con semáforo, cifras (sin atender, en proceso, resueltos) y filtros por nivel. Al tocar un
                  reporte se abre: diagnóstico, si requiere compra o cambio y costo estimado.
Preventivo        revisiones programadas: vencido (rojo), hoy (amarillo) y próximos. "Ya se revisó" la reprograma;
                  "Posponer" pide motivo y nueva fecha.
Equipos           catálogo por salón con foto; salones y zonas.
Reportes gerencia lo que ve Control Gerencia (solo lectura): solo reportes de instructores de Fitness.
Al final de Reportes hay "Datos de prueba": cargar y borrar reportes de ejemplo.

CÓMO SUBIRLA
------------
1) En el repositorio: Add file -> Upload files. Arrastra el CONTENIDO de esta carpeta (index.html, sw.js,
   manifest.json, LEEME.txt y las carpetas css, js, img), no la carpeta en sí. Commit changes.
   (Los archivos con el mismo nombre se reemplazan. css/app.css ya no se usa: puedes borrarlo del repositorio.)
2) Settings -> Pages -> rama main, carpeta / (root).
3) https://cfitnesscampestre-star.github.io/control-mantenimiento/
4) Si el celular no toma el cambio, ciérrala por completo y ábrela otra vez.

REGLAS DE FIREBASE
------------------
{ "rules": { ".read": true, ".write": true, "reportes": { ".indexOn": ["profId"] } } }
Con reglas abiertas cualquiera que conozca la dirección puede leer o escribir. Antes de usarla con todos los
instructores hay que cerrarla con autenticación.

PRIMER USO
----------
1) Equipos -> "Cargar los salones de Fitness": Salón 1, Salon Spinning, Salon Yoga, Salon 2, Salon3, Box y
   CrossFit, con los mismos nombres que en Control Fitness.
2) Equipos -> Agregar: nombre, salón y nombre del archivo de foto (o "Cargar catálogo de ejemplo" para probar).
3) Preventivo -> Agregar revisión: qué se revisa, dónde, frecuencia y próxima fecha.

FOTOS DE EQUIPOS
----------------
Se suben a la carpeta img/equipos del repositorio y se llaman por nombre de archivo (ver img/equipos/LEEME.txt).

AL SUBIR CAMBIOS
----------------
Sube el número ?v= en index.html y VERSION en sw.js (van juntos). Si agregas archivos nuevos en css/, js/ o img/,
agrégalos a la lista ARCHIVOS de sw.js.

ESTRUCTURA DE DATOS
-------------------
/salones/{id}    { nombre, area }
/equipos/{id}    { nombre, salonId, foto }
/reportes/{id}   reportes ABIERTOS:
                 { equipoId, desc, urg: "normal"|"urgente"|"fuera", profId, prof, area, clase, salonId, otroLugar,
                   creado (ms), estado: "nuevo"|"atencion"|"resuelto", visto (ms), diag, compra, cambio, costo,
                   resuelto (ms), origen: "fitness" (opcional) }
/historial/{id}  reportes que el instructor ya eliminó (se mueven aquí con cerrado = ms)
/preventivo/{id} { titulo, detalle, salonId, freq (días), proxima (ms), posp[], hist[] }
Control Gerencia reconoce un reporte de Fitness por origen:"fitness" o porque profId es el número de instructor.

LÍMITES CONOCIDOS
-----------------
- Sin internet: los cambios se envían al volver la señal, pero solo si la app sigue abierta.
- Sin PIN ni autenticación todavía.
- El repositorio es público: el código y las fotos de los equipos son visibles con el enlace.
